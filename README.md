#Maruleng Municipality Application – Part 2

#Project Overview

The Maruleng Municipality Application is a C# Windows Forms application designed to help residents access municipal information and report or track community issues.

Part 2 focuses on Local Events and Announcements and Track Service Requests.

Features

1. Local Events and Announcements

View upcoming community events and municipal notices.

Search for events using keywords.

Filter events by category and date.

Receive related event recommendations based on previous searches.

Manage event information using different data structures.

2. Track Service Requests

View submitted service requests.

Check the status of reported issues.

Help residents follow up on their service requests.

Technologies Used

C#

Windows Forms

.NET

Visual Studio

Data Structures

The application uses the following data structures to manage event information:

List: Stores event records.

Queue: Supports first-in, first-out event processing.

Stack: Stores search history.

Dictionary: Retrieves events using their IDs.

SortedDictionary: Groups events by date.

HashSet: Stores unique event categories.

Priority-based collection: Supports retrieving events according to priority.

How to Run the Application

Clone or download this repository from GitHub.

Open the solution file (.sln) in Visual Studio.

Restore any required dependencies if prompted.

Build the solution.

Run the application.

Testing

The application can be tested by:

Viewing the events and announcements.

Searching for events using keywords.

Filtering events by category and date.

Checking the related event recommendations.

Viewing submitted service requests and their statuses.
